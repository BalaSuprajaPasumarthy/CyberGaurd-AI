# CyberGuard AI

## AI-Powered Cyber Threat Detection System

CyberGuard AI is a machine learning-based cybersecurity system designed to detect and classify cyber threats from network and industrial control system data. The project uses machine learning and deep learning techniques to identify abnormal or malicious activity and support real-time cyber attack detection.

## Features

- Dataset upload and data preprocessing
- Cyber threat detection and classification
- Feature extraction using AutoEncoder
- Dimensionality reduction using PCA
- Decision Tree-based classification
- Deep Neural Network (DNN) classification
- Model performance evaluation
- Accuracy, Precision, Recall and F1-Score analysis
- Graphical user interface for interacting with the system

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Tkinter
- PCA
- AutoEncoder
- Decision Tree
- Deep Neural Network (DNN)
- HTML
